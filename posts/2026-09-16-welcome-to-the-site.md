This is the first post on **prototypesandprogramming.com**. I built this site to have a home base for the robotics, machine learning, and 3D printing projects I've been working on, plus a place to write up what I learn along the way.

## How the blog works

Every post here is just a markdown file dropped into the `posts/` folder of the site's repo. There's no build step and no CMS — the site reads the folder straight from GitHub and renders whatever it finds.

To publish a new post, all I need to do is:

1. Add a new `.md` file to `posts/`, named like `YYYY-MM-DD-my-title.md`.
2. Add a short frontmatter block at the top with a `title`, `date`, `tags`, and `excerpt`.
3. Write the post in plain markdown below it.
4. Push to GitHub.

That's it — no rebuild, no redeploy step, no extra file to edit.

## What's next

Expect posts here about robotics projects, things I'm 3D printing, and notes from whatever I'm learning next.
