Copy this file to get the frontmatter format right when starting a new post.

```
---
title: Your Post Title
date: 2026-10-01
tags: [robotics, ml]
excerpt: One sentence describing the post for the blog list.
---
Your post content goes here, written in normal markdown.
```

### Formatting cheatsheet

- `**bold**` and `*italic*` both work.
- `[link text](https://example.com)` for links.
- `![alt text](images/photo.jpg)` for images — drop the image in the `images/` folder first.
- Fenced code blocks with three backticks, like the example above.
- `#`, `##`, `###` for headings.
- Lines starting with `-` for bullet lists, or `1.` for numbered lists.

Delete this post once you're comfortable with the format, or leave it up as a reference.
